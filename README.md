# Website Desa Semparuk

Website landing page Desa Semparuk, Kecamatan Semparuk, Kabupaten Sambas, Kalimantan Barat.

## Struktur
- `index.html` — halaman utama
- `style.css` — desain dan responsive layout
- `script.js` — menu mobile, animasi scroll, tombol kembali ke atas

## Cara menjalankan
Buka `index.html` di browser.

## GitHub Pages
1. Buat repository baru di GitHub.
2. Upload `index.html`, `style.css`, `script.js`, dan folder `assets`.
3. Pastikan nama halaman utama tetap `index.html`.
4. Buka Settings → Pages.
5. Pilih branch `main` dan folder `/root`.
6. Simpan, lalu tunggu GitHub Pages menerbitkan website.

Catatan:
Foto pada versi awal menggunakan gambar web sebagai contoh visual. Untuk versi resmi, sebaiknya diganti dengan foto asli Desa Semparuk dan logo resmi desa.
